# Extrato IA

Extrato bancário (.OFX/.CSV/.XLSX de vários bancos) → lançamentos categorizados (regras locais + IA BYOK via OpenRouter só com descrições mascaradas) → DRE gerencial, fluxo de caixa, assinaturas, fechamento escrito por IA e planilha .xlsx para o contador. Tudo calculado no navegador; o único backend é o gate n8n compartilhado. Ferramenta da Comunidade Maestros da IA.
